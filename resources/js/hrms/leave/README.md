# Leave Management UI

This folder contains React components for managing employee leaves:
- `add.jsx`: Apply for leave
- `edit.jsx`: Approve/Reject or edit leave
- `list.jsx`: List and report of leaves

UI and code structure follows the pattern of the attendance management module for consistency.

**Features:**
- Leave request (apply)
- Approval/rejection (admin/manager)
- Leave reports (list, filter)

API endpoints are defined in `api.php` and handled by `LeaveController.php`.
